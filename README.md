# Geoquiz

Небольшая игра для изучения географии: угадывай страны, подсвеченные на карте мира.

## Возможности
- Случайная страна на карте
- Ответ на русском или английском (для некоторых стран — распространённые альтернативные названия)
- Повторная попытка, показать ответ и перейти к следующему вопросу
- Счёт правильных ответов и вопросов, сохраняемый в браузере
- Адаптивный дизайн

## Запуск
Открой `index.html` в браузере. Для загрузки геоданных и библиотек нужен интернет.

## Публикация
GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**. Репозиторий private; доступность Pages зависит от тарифа и настроек аккаунта.

## Стек
HTML/CSS/JS, D3.js, topojson-client, world-atlas 110m (через jsDelivr).

## Идеи на будущее
Уровни сложности, регионы, режим выбора из четырёх вариантов, повторение ошибок, статистика по странам.
